# Security

Orbit handles a camera, a microphone, an API key and (optionally) your computer screen, so
security reports are very welcome.

**Please report security problems privately**, using GitHub's **Security → Report a
vulnerability** on this repository, not in a public issue.

Good things to report: anything that sends data off the phone without the person asking,
ways around the Orbit Desk pairing code, ways to read the API key from outside the app, and
anything that lets another device on the network control Orbit.

Users: keep your Gemini API key to yourself, and run Orbit Desk only on networks you trust.
